About

Share any Obsidian note as a styled webpage and copy the public link instantly via htmlto.link. Pick from 30+ templates and multiple theme variants, choose card widths (360–800px), never share linked files, write share_link/share_updated to frontmatter, and use a self-hostable API base URL.
